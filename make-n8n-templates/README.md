# 🔗 Make / n8n Automation Templates

Готовые JSON-шаблоны рабочих процессов (workflows) для визуальных платформ автоматизации. Экономьте десятки часов ручной пересылки данных между сервисами.

## 📦 Что внутри
- **form-to-crm-telegram.json**: Классическая связка "Сайт → CRM → Telegram". Заявка с формы мгновенно создаёт лид в Bitrix24/AmoCRM и отправляет уведомление ответственному менеджеру.

## 🚀 Как использовать
1. Экспортируйте или скопируйте содержимое `.json` файла.
2. В Make.com или n8n создайте новый сценарий и импортируйте этот JSON (или воссоздайте узлы по описанию).
3. Подключите свои API-ключи (Bitrix24, Telegram Bot Token).
4. Скопируйте URL вебхука и вставьте его в настройки формы на вашем сайте (Tilda, WordPress, самописный сайт).
5. Активируйте сценарий и сделайте тестовую отправку.

## 💡 Почему это выгодно
- **Скорость:** Настройка занимает 15–30 минут.
- **Надёжность:** Платформы вроде Make/n8n сами обрабатывают ошибки и повторные попытки отправки.
- **Масштабируемость:** Легко добавить новый шаг (например, отправку email или запись в Google Таблицу) без изменения кода сайта.
