# ⚙️ Automation Examples

Коллекция готовых решений и скриптов для автоматизации рутинных бизнес-процессов. Минимум ручного труда, максимум эффективности.

## 📂 Проекты в этом репозитории

### 1. [Telegram → Google Sheets](./telegram-to-google-sheets)
Автоматическая синхронизация: заявки из Telegram-бота мгновенно попадают в структурированную Google-таблицу с датой и статусом.
- **Технологии:** Python, Aiogram 3.x, Google Sheets API (gspread).
- **Время внедрения:** ~1 день.

### 2. [Make / n8n Templates](./make-n8n-templates) *(в процессе добавления)*
Готовые JSON-шаблоны рабочих процессов (workflows) для визуальных платформ автоматизации: форма на сайте → CRM → уведомление в Telegram.
